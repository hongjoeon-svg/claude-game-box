# 뽑기방 건물주 (가제)

집게 하나로 인형을 뽑아 돈을 벌고, 기계를 늘려 인형뽑기방을 통째로 키우는 인크리멘털 게임.
세로 화면 아이폰 앱(Capacitor)으로 출시하는 것이 목표입니다.

## 현재 진행 단계: 1단계 — 손맛 프로토타입

- [x] 기계 1대, 레버로 집게 좌우 이동 (관성 + 대롱대롱 흔들림)
- [x] 뽑기 → 내려감 → 인형에 닿으면 멈칫 → 오므림 (인형에 닿은 집게발은 거기서 멈춤)
- [x] 잡힌 위치(가운데/가장자리, 깊이)로 "잡힌 정도" 계산 → 버틸 확률 결정
- [x] 놓치는 연출: 들자마자 툭 / 꼭대기에서 덜컹 / 옮기다가 — 직전에 덜덜 흔들리며 버팀
- [x] 성공하는 판에도 가끔 아슬아슬하게 흔들림 ("휴… 버텼다!")
- [x] 배출구로 떨어지면 코인 획득 (놓친 인형이 굴러 들어가면 "덤")
- [x] 효과음(합성음), 화면 흔들림, 파티클, 한국어 멘트
- [ ] 2단계: 업그레이드 상점, 인형 등급, 저장/불러오기
- [ ] 3단계: 기계 추가, 자동 뽑기, 오프라인 수익
- [ ] 4단계: 엔딩, 효과음 정리, 밸런스
- [ ] 5단계: Capacitor iOS 프로젝트

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
cd claw-landlord
npm install
npm run dev
```

터미널에 나오는 `Local: http://localhost:5173/` 주소를 PC 브라우저로 열면 됩니다.
PC에서는 `←` `→` 키로 이동, `스페이스`로 뽑기.

### 휴대폰으로 테스트하기

1. PC와 휴대폰을 **같은 와이파이**에 연결합니다.
2. `npm run dev` 를 실행하면 터미널에 `Network: http://192.168.x.x:5173/` 주소가 함께 나옵니다.
3. 휴대폰 사파리/크롬에서 그 주소를 엽니다.
   - 안 열리면 PC 방화벽에서 5173 포트(또는 Node.js)를 허용해 주세요.
4. (선택) 사파리 공유 버튼 → "홈 화면에 추가" 하면 주소창 없이 전체 화면으로 열립니다.
5. 소리는 화면을 한 번 터치한 뒤부터 납니다 (iOS 정책). 무음 모드 스위치가 켜져 있으면 안 들릴 수 있어요.

### 손맛 튜닝 모드

주소 끝에 `?debug` 를 붙이면 (예: `http://192.168.x.x:5173/?debug`)

- 화면 오른쪽에 슬라이더 패널이 뜨고, 집게 힘·속도·흔들림 등을 실시간으로 바꿀 수 있습니다.
- 기계 안에 충돌선과 "잡힌 정도 / 버틸 확률 / 결과"가 표시됩니다.
- 마음에 드는 값이 나오면 "현재 값 복사"를 눌러 알려 주시거나 `src/config.ts` 에 직접 적으면 됩니다.

### 빌드

```bash
npm run build        # dist/ 에 배포용 파일 생성
npm run build:site   # play/ 에 생성 (게임 모음 사이트의 링크용)
```

## 수치 조정

**모든 밸런스·손맛 수치는 `src/config.ts` 한 파일에 있습니다.** 주석에 각 값의 의미를 적어 두었습니다.

| 하고 싶은 것 | 고칠 값 |
| --- | --- |
| 인형을 덜 놓치게 | `grip.strength` ↑ |
| 집게를 더 빠르게 | `claw.moveMaxSpeed`, `descendSpeed`, `liftSpeed` |
| 집게가 덜 흔들리게 | `claw.swayFromAccel` ↓ 또는 `swayDamping` ↑ |
| 놓치기 직전 긴장감을 길게 | `grip.wobbleTime` ↑ |
| 언제 놓치는지 비율 | `grip.dropWhen` |
| 인형 수 | `machine.dollCount` |
| 광고 끄기 (유료 앱) | `ads.enabled = false` |

## 그림·소리 교체

- `src/assets.ts` 의 `SPRITES` / `SOUNDS` 에 경로를 적고 파일을 `public/assets/` 에 넣으면 됩니다.
  비어 있는 항목은 코드로 그린 플레이스홀더/합성음이 쓰입니다.
- 인형 종류·이름·가격은 `src/data/dolls.ts`. 모두 오리지널 캐릭터(말랑곰, 졸린토끼, 식빵냥, 감자햄찌, 개굴이, 두부씨, 만두찐, 뒤뚱펭, 달팽배달)입니다.

## 폴더 구조

```
src/
  config.ts              모든 수치
  assets.ts              이미지·소리 경로
  data/dolls.ts          인형 목록
  game/Machine.ts        기계 1대 = 물리 세계 + 집게 상태 기계 (3단계에서 여러 대 생성)
  render/                캔버스 그리기 (캐비닛, 인형, 집게)
  fx/Effects.ts          파티클, 글자, 배너, 화면 흔들림
  audio/Sfx.ts           효과음 (Web Audio 합성)
  platform/haptics.ts    진동 — 5단계에서 Capacitor Haptics로 교체
  ui/                    HUD, 레버/버튼, 디버그 패널
  main.ts                연결 + 메인 루프 (물리 60Hz 고정 스텝)
```

## 기술 메모

- Vite + TypeScript + Matter.js, Canvas 렌더링, 서버 없음.
- `vite.config.ts` 의 `base: './'` 는 Capacitor에서 상대 경로로 파일을 읽기 위해 필요합니다.
- 놓칠지 말지는 집게가 닫히는 순간 확률로 미리 정해 두고, 물리(스프링으로 매달기, 흔들림, 미끄러짐)로 연출합니다.
  순수 물리 마찰만으로 잡게 하면 기기마다 결과가 들쭉날쭉하고 업그레이드 수치로 조절하기 어렵기 때문입니다.
  대신 집게발·몸통은 실제 충돌체라 인형을 밀고, 건드리고, 굴릴 수 있습니다.
